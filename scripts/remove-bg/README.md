# remove-bg — пакетное удаление фона с фото (rembg + BiRefNet)

Делает прозрачные PNG (alpha) из продуктовых фото — готово для Figma.

## Установка (изолированно, через uv)
```powershell
uv venv .venv --python 3.12
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
```

## Запуск
```powershell
.venv\Scripts\python.exe remove_bg.py "D:\РАКИСВЕЖЕЕ\theraki-qr-menu\фото"
```
Результат → `фото\cutout\*.png` (прозрачный фон).

### Опции
- `--out <папка>` — куда класть (по умолчанию `<input>\cutout`).
- `--model` — выбор модели. **По умолчанию `isnet-general-use`** — держит ВСЮ тарелку/миску (нужно для продуктовых фото блюд). `u2net` — почти то же. НЕ используй `birefnet-general` для блюд на тарелке: он salient-модель, выкидывает посуду и оставляет только еду.
- `--alpha-matting` — доп. уточнение краёв (медленнее; для пушистых/полупрозрачных краёв).
- `--overwrite` — переобработать уже готовые.

## Заметки
- Первый запуск **скачивает модель** автоматически (BiRefNet большой). Дальше — из кэша.
- BiRefNet на CPU не быстрый: считай ~секунды–десятки секунд на фото. 13 фото — пара минут.
- Если нужен матовый фон под печать, а не прозрачный — скажи, добавлю флаг заливки цветом.
