## 2. Система воздуха и ритма (40–50% воздуха)

База **8px-сетки**, токены уже в `:root` (`globals.css:62-70`): `2xs 4 / xs 8 / sm 16 / md 24 / lg 32 / xl 48 / 2xl 72 / 3xl 112`.

- **Колонка:** `max-width:720px`, центр. Боковые поля **24px** (≥768px → **32px**). Книжная мера ~44–46ch. Контент никогда не на всю ширину.
- **Между главами:** padding главы **72px** (`--space-2xl`) сверху + снизу → между соседними **144px** дыхания. На экране 844px заголовок+2–3 позиции занимают ~50%, остальное пусто.
- **Глава после тёмного разворота:** верхний padding ужать до **32px** (`--space-lg`) — арка дивайдера уже дала воздух (класс `.chapter--after-divider`, `globals.css:403`).
- **Шапка главы:** `title ↔ origin` baseline в одну строку (`space-between`) → lede 14.5px с `margin-bottom:32px` → hairline 1px → ещё **32px** до первой строки. Заголовок дышит сверху и снизу одинаково.
- **Между позициями:** строка карты padding **14px** сверху/снизу (ритм 28px). Разделитель — `1px` `--hairline-soft` (0.08) **только между** строками (`.row + .row`), не у краёв. Первая/последняя без линии — список «парит».
- **Раскрытое описание (note):** `margin-top:6px` + `padding-bottom:14px`, соседи мягко раздвигаются (grid `0fr→1fr`, см. §4).
- **Флагман Tier A:** фото full-bleed по колонке → **24px** → имя↔цена baseline → **8px** → eyebrow-провенанс → **32px** до списка позиций.
- **Фото ↔ текст:** минимум **32px** (`--space-lg`) воздуха сверху и снизу любого фото — фото всегда «висит в белом».
- **Матрица раков:** отступ от рецептов 32px, caption padding 16/8px, строки таблицы **9px** по вертикали (плотнее — это «биржевая котировка»).
- **Колофон:** padding **112px** сверху / **72px** снизу — максимум воздуха в документе.
- **[graft] safe-area:** колофон и последняя строка — `padding-bottom: calc(72px + env(safe-area-inset-bottom))`. `scroll-padding-top` под sticky-nav = `48px` (палец на iPhone не упирается, контент не заходит под nav).

## 4. Микровзаимодействия и анимации (8)

Единый easing для всех: **`cubic-bezier(0.22, 1, 0.36, 1)`** = `--ease-out`. Каждое имеет `prefers-reduced-motion`-фоллбек.

**1. Hero-интро «проявка»** — триггер: load обложки. Эффект: каскад снизу-вверх eyebrow→wordmark→rule(scaleX 0→1)→sub→year→hint, каждый `opacity 0→1 + translateY(14px→0)`; фон одновременно `filter:blur(8px)→0`. Stagger 120/240/460/560/660/1100ms. ms: 860/элемент, blur 1200. impl: `@keyframes cover-rise` + `animation-delay` (`globals.css:155-205`, уже стоит); blur добавить в тот же keyframe. **reduced:** `animation:none; opacity:1; blur:0` (`globals.css:210`).

**2. Волна тёмное→крем (один раз)** — триггер: скролл обложка→первая кремовая глава. Эффект: кремовая арка `border-radius:100% 100% 0 0` поднимается из-под тёмной обложки. ms: 0 (статическая форма, нативный скролл). impl: `.cover__arch` (`globals.css:299`), без JS. **reduced:** без изменений (форма статична).

**3. Reveal текста при скролле** — триггер: IntersectionObserver, элемент на 12% во вьюпорте. Эффект: `opacity 0→1 + translateY(14px→0)`, без X-движения и scale. ms: 860. impl: IO `threshold:0.12, rootMargin:-8% снизу` добавляет `.is-in` на `.reveal` (`globals.css:1106-1117`); `unobserve` после первого срабатывания. **reduced:** `opacity:1; transform:none; transition:none` (`globals.css:1119`).

**4. Reveal фото (slow scale-settle)** — триггер: IO, фото-флагман входит. Эффект: внутри арки `transform:scale(1.06)→1 + opacity 0→1`, маска неподвижна (`overflow:hidden`). ms: **2400**. impl: тот же IO, класс `.photo-settle.is-in` (паттерн `.divider.is-in .divider__media img`, `globals.css:481`). **reduced:** `transform:none; transition:none`.

**5. Нажатие на блюдо — раскрытие note** — триггер: tap по строке (вся строка = `<button>`, `min-height:44px`). Эффект: note `grid-template-rows:0fr→1fr + opacity 0→1`, соседи раздвигаются без скачка; активное имя получает золотой `#be9667` `border-left:0→2px`. ms: 360 (rows) / 220 (opacity). impl: CSS grid-rows transition + React `aria-expanded` (паттерн `ledger.css` + `expandable.tsx`). **reduced:** `transition:none` (мгновенно).

**6. [graft] Press-feedback** — триггер: `:active` по строке. Эффект: `transform:scale(0.99)`. ms: 120. impl: чистый CSS `:active` под guard `@media (hover:hover)` ИЛИ только `:active` — НЕ на тач-hover, чтобы не превратилось в «приложение». **reduced:** `transform:none`.

**7. Скролл-нав: золотая нить-закладка** — триггер: scroll + активная глава. Эффект: под sticky-nav золотой `#be9667` `1px` растёт `scaleX 0→1` пропорционально прочитанному; активный чип — `--ink` + золотой `border-bottom`, `scrollIntoView({inline:'center'})`. ms: 160 (чип) / нить — rAF по скроллу. impl: `.nav__thread` `transform:scaleX()` (`globals.css:325`) + IO для активной главы. **reduced:** нить статична на 100% активной, `scroll-behavior:auto`.

**8. [graft] Острые позиции — тихий сигнал** — триггер: reveal строки `spicy:true`. Эффект: золотая точка-перчик `opacity 0→0.8`, `transition-delay:400ms` после reveal; не мигает. ms: 600. impl: `::after` transition активируется `.is-in`. **reduced:** `opacity:0.8` сразу.

## 5. Переход на деталь блюда

Полноэкранная карточка через **View Transitions API** (shared-element morph, не slide-in — это не «приложение»).

- **Триггер:** тап по иконке-стрелке флагмана (или long-press строки).
- **Эффект:** фото-арка `morph`-увеличивается из карточки в full-bleed hero детали; имя блюда плавно переезжает наверх; остальное (описание, провенанс, цена) проявляется `opacity 0→1`. Никакого горизонтального slide — только проявка + рост.
- **ms:** 500 вперёд / 420 назад. **easing:** `cubic-bezier(0.22,1,0.36,1)`.
- **impl:** `view-transition-name` на фото-арке (напр. `vt-dish-{id}`) и на имени блюда; `document.startViewTransition(() => navigate())` при переходе. Назад — обратный morph (браузер инвертирует автоматически).
- **Fallback** (нет API / reduced-motion): мгновенная смена маршрута + короткий `opacity 180ms`. Это единственный непроверенный кусок системы — обязателен graceful degrade, без него навигация всё равно работает.

## 6. Signature-фишка (одна)

**«Проявка» (Develop-on-scroll).** Каждый из 13 флагман-кадров входит из `blur(8px)→0` + `scale(1.06)→1` одновременно, медленно (**2400ms**), внутри неподвижной арочной маски-окна.
